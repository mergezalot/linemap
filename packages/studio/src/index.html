      Map
      
        
      
          
      Zoom
      Ctrl+wheel · pinch · + -
      
          
      Fit
      0
      
          
      Pan
      drag · wheel · arrow keys
      
          
      Pin lines
      click a line or node · Shift adds · Esc clears
      
          
      Hide a line
      click its legend row · Shift: only it
      
          
      Open a link
      Ctrl-click a node
      
          
      Search
      / · Ctrl F
      
          
      Next theme
      T
      
          
      Notes on / off
      N
      
          
      Reload
      R
      
          
      Open a file
      Ctrl O · drop · paste
      
        
      
        
      Source, in edit mode
      
        
      
          
      Find
      Ctrl F in the text
      
          
      Leave the text
      Esc
      
        
      
      
      
      
      
        
      Edit E
      
        
      
          
      Move · bend
      drag a box · a line
      
          
      Resize
      click a selected box again, drag a handle
      
          
      New box
      double-click the map
      
          
      Connect
      drag a box's + onto another
      
          
      Reattach
      drag a selected edge's end onto a box
      
          
      One line
      click a selected edge again
      
          
      Remove a bend
      double-click it
      
          
      Edit text
      double-click · F2
      
          
      Container
      click: select · again: its boxes · drag: all in it
      
          
      Select several
      Shift+drag · Shift-click
      
          
      Same size
      click one of several selected again
      
          
      Pin · unpin
      P
      
          
      Lines of an edge
      L
      
          
      Remove
      Del
      
          
      Undo · redo
      Ctrl Z · Ctrl Shift Z
      
          
      Off the grid
      Alt while dragging
